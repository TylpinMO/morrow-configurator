# Morrow Configurator

Интерактивный конфигуратор настольной лампы Morrow 01. Проект показывает работу со сложным состоянием интерфейса, адаптивной компоновкой и векторной графикой без внешних изображений.

## Highlights

- четыре варианта отделки, две высоты и два типа крепления;
- три температуры света с изменением визуализации;
- цельная SVG-модель лампы, связанная с выбранной конфигурацией;
- переключение ракурсов и демонстрационная корзина;
- адаптивная вёрстка, управление с клавиатуры и reduced motion.

## Stack

React 19, TypeScript, Vite, SVG и CSS.

## Локальный запуск

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run lint
npm test
```

## Развёртывание

Проект подготовлен для Vercel: команды установки, сборки и каталог `dist` заданы в `vercel.json`. Переменные окружения не требуются.
